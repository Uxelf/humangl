# HumanGL
As a follow up of the other 3D graphics related proyect, Scop, this proyect aims to make and manage animations, and handle transformations.



https://github.com/user-attachments/assets/3b78aae6-b3f0-4a4a-98af-7ce2815e3786




## Instructions
Download the project and execute `make` inside the folder
You can execute the program with `./humangl`

## Controls
**Arrows** - Move arround  
**UI** - All what you need to control the humanoid and save, load and manage animations.
